# DSA 期末考前学案

> 依据 `DSA期末错题总结_按对话代码来源校订版.pdf`、`tree.md`、`graph.md` 整理。核心目标不是再背一遍代码，而是练会：看到实例以后，知道模板里的哪些部分必须改。

## 一、这份作业暴露出的知识点总览

### 1. 树、二叉树、BST、堆、Huffman

作业中的树题并不是单纯考“会不会遍历”，而是在考你能不能把遍历模板改成题目要求的输出。

| 题目 | 核心知识点 | 容易不熟的地方 |
|---|---|---|
| 22 根据二叉树前中序序列建树 | 前序 + 中序确定树，输出后序 | 不一定要真的建树；切前序时必须用左子树长度 |
| 23 括号嵌套二叉树 | 字符串解析建树，前序/中序遍历 | 不能直接按逗号 split，要按括号深度找最外层逗号 |
| 24 二叉树 | 完全二叉树编号，子树节点计数 | 不建树，用每层编号区间 `[left,right]` 扩张 |
| 25 二叉搜索树的层次遍历 | BST 插入 + BFS 层序 | 重复值忽略；层序要用队列 |
| 26 实现堆结构 | 最小堆，插入与删除最小值 | `heapq` 拼写、每组数据重新建堆、操作行长度不同 |
| 27 树的转换 | 普通树转左儿子右兄弟二叉树，高度变化 | 原树高度和转换后二叉树高度口径不同；兄弟边也算高度 |
| 28 Huffman 编码树 | 最小堆反复合并，求最小 WPL | 答案是每次合并和的累计，不是最后根权值 |
| 49 二叉树的深度 | 递归求树深度 | 根固定为 1；深度按节点数，不是边数 |
| 50 扩展二叉树 | 扩展先序 `.` 表空，输出中序/后序 | 用全局下标/迭代器读，不能每次从头读 |
| 53 根据二叉树中后序序列建树 | 中序 + 后序确定树，输出前序 | 后序最后一个是根；切后序仍要靠左子树长度 |
| 54 验证二叉搜索树 | BST 合法性，范围递归 | 不能只比较父子，要用上下界约束整棵子树 |

个人薄弱点倾向：

- 你能理解 `tree.md` 里的遍历模板，但题目往往要求“换输出顺序”或“只输出某种遍历”，所以要先判断：是否真的需要建节点。
- 你容易把“概念结构”写得完整，但竞赛题更需要短实现：字符串递归、数组保存左右孩子、编号区间，都比完整类更合适。
- 堆相关题容易在 API 和初始化上出错：`heapq.heapify`、`heappush`、`heappop`，多组数据时每组 `heap=[]`。

### 2. 图、BFS、最短路、MST、拓扑

图题的关键不是会不会 BFS，而是判断“这个题到底还能不能用普通 BFS”。

| 题目 | 核心知识点 | 容易不熟的地方 |
|---|---|---|
| 1 单词序列 | 单词图 BFS，最短变换序列 | 建图方式、距离从序列长度 1 开始 |
| 2 仙岛求药 | 网格 BFS，最短步数/经过格子数 | 起点是否计入答案；多组/终止条件 |
| 3 变换的迷宫 | 状态 BFS，时间模数 | `visited[x][y][t % K]`，不能只存二维 visited |
| 1 拓扑排序 | DAG 入度 + 最小堆 | 题目要求编号小优先时，队列要换最小堆 |
| 2 丛林中的路 | Kruskal MST | 字母转编号；无向边；并查集 |
| 3 A Walk Through the Forest | Dijkstra + 记忆化 DFS 计数 | 先从终点 2 跑最短路，再沿 `dist` 严格下降方向计数 |
| 4 打怪救公主 | 最优资源 BFS | visited 不能是布尔，要记录到达格子的最大剩余血量 |
| 5 兔子与樱花 | Floyd + 路径恢复 | 不只求最短距离，还要输出路径，每条边的距离要能打印 |
| 56 拯救行动 | 网格 Dijkstra | 进入普通格代价 1，进入守卫格代价 2，普通 BFS 不保证最优 |
| 57 连接所有点的最小费用 | 完全图 MST，Prim | 不需要存所有边，曼哈顿距离可即时计算 |

个人薄弱点倾向：

- 你最需要训练的是“状态设计”。普通 BFS 的状态是 `(x,y)`，但变形题会变成 `(x,y,t%K)`、`(x,y,剩余血量)`、`(x,y,当前时间)`。
- 你容易把最短路、路线计数、最小生成树混在一起。题面说“到某点最短”是最短路；说“所有点连通总代价最小”是 MST；说“路线数量”通常要 DP/记忆化。
- `graph.md` 里有对象式图结构，但作业代码多用列表/矩阵/字典。考试时优先用轻量结构，不要把 Vertex/Graph 类硬搬进去。

## 二、从 md 模板到作业实例：到底要改哪里

### 1. BFS 模板的迁移

`graph.md` 的普通 BFS 模板是：

```python
q = deque([(sx, sy, dist)])
visited[sx][sy] = True
while q:
    x, y, d = q.popleft()
    for dx, dy in dirs:
        ...
```

作业中它被扩展成四类：

| 模板问题 | 作业题 | 必须改的地方 |
|---|---|---|
| 普通无权最短路 | 仙岛求药、单词序列 | 状态仍是一维/二维位置；第一次到终点就是最短 |
| 带时间周期 | 变换的迷宫 | `visited` 从二维变三维：`visited[x][y][t % K]` |
| 资源越多越好 | 打怪救公主 | `visited` 改成 `best[x][y]`，只有剩余血量更大才入队 |
| 边权不同 | 拯救行动 | 队列改成优先队列，升级为 Dijkstra |

记忆句：

普通 BFS 只适合“每一步代价完全相同”。只要出现不同代价、等待时间、钥匙、血量、时间周期，第一反应就是：状态要加维度，或者改成 Dijkstra。

### 2. Dijkstra 模板的迁移

`graph.md` 中 Dijkstra 是从一个起点求所有点最短路。作业里有两种变形：

- 拯救行动：把网格看成图，每个格子是点，进入邻居的代价是 1 或 2。
- A Walk Through the Forest：不是从办公室 1 跑，而是从家 2 跑，得到每个点“到家距离”。

迁移步骤：

1. 明确点是什么：普通图的点、网格格子、单词、地点名。
2. 明确边权是什么：移动一步、进入守卫、道路长度、曼哈顿距离。
3. 明确起点是谁：有时题目问从 1 到 2，但算法要反向从 2 跑。
4. 若要计数，Dijkstra 只负责提供 `dist`，路线数还要 DFS/DP。

### 3. Floyd 模板的迁移

`graph.md` 里的 Floyd 求所有点对最短路，作业的“兔子与樱花”还要求输出路径。

模板要补两件事：

- `dist[i][j]`：最短距离。
- `nxt[i][j]` 或 `prev[i][j]`：路径恢复。

考试判断：

- 点数小，多次查询，地点可能是字符串：Floyd 很合适。
- 如果只问一次从 A 到 B，且边权非负：Dijkstra 更合适。
- 如果要求打印 `A->(d)->B`，不能只保存总距离，必须保存路径上的相邻点。

### 4. MST 模板的迁移

`graph.md` 里 Prim/Kruskal 都讲了，作业里两种 MST：

| 作业题 | 图的形态 | 更自然的算法 |
|---|---|---|
| 丛林中的路 | 显式给边，点是字母 | Kruskal：收集边、排序、并查集 |
| 连接所有点的最小费用 | 完全图，边权由坐标算出 | Prim：不存所有边，动态更新 `minDist` |

判断口诀：

- 边已经一条条给你：Kruskal 很顺。
- 每两个点都有边，但边权能现场算：Prim 更省。
- “连通且总代价最小”“任意两点之间有且仅有一条简单路径”：都是 MST。

### 5. 树遍历模板的迁移

`tree.md` 中的前序/中序/后序是基础，作业变形在于“输入给的不是树对象”。

| 输入形式 | 作业题 | 解法 |
|---|---|---|
| 前序 + 中序 | 22 | 根是 `pre[0]`，用中序切左右，输出后序 |
| 中序 + 后序 | 53 | 根是 `post[-1]`，用中序切左右，输出前序 |
| 扩展先序，`.` 表空 | 50 | 用下标顺序读，遇 `.` 返回空 |
| 括号嵌套 | 23 | 根是第一个字符，括号内部按最外层逗号切左右 |
| 编号给左右孩子 | 49 | 数组 `left/right`，从根 1 递归 |

关键提醒：

- 题目只要输出遍历序列时，不一定要建完整节点对象。
- 但如果输入格式复杂，例如括号嵌套、扩展二叉树，建树会让遍历更清晰。
- “空树返回什么”取决于输出：输出字符串就返回 `''`，求深度就返回 `0`。

## 三、逐题：作业比 md 多出的拓展/补充

### 22 根据二叉树前中序序列建树

`tree.md` 讲了前序 + 中序重建原则，作业补充了“多组输入到 EOF”和“输出后序”。所以模板要加：

- 循环读两行。
- 建树后后序遍历，或者直接递归返回后序字符串。
- 切前序时用左子树长度，而不是用根在前序中的位置。

### 23 括号嵌套二叉树

md 中没有重点讲括号字符串解析。作业补充的是“表达式解析”能力：

- 根是当前字符串第一个字符。
- `A(B,C)` 的左右子树在最外层逗号处分开。
- 嵌套里面的逗号不能切，所以要维护括号深度。

这是从“会遍历树”到“会把字符串变成树”的拓展。

### 24 二叉树

`tree.md` 讲完全二叉树编号性质：左孩子 `2p`，右孩子 `2p+1`。作业要求反过来问“以 m 为根的子树实际有多少节点”。不用建树，直接每层扩张：

```text
第 0 层：[m, m]
第 1 层：[2m, 2m+1]
第 2 层：[4m, 4m+3]
每层与 n 截断
```

这是从“结构性质”到“编号区间计算”的拓展。

### 25 二叉搜索树的层次遍历

`tree.md` 有 BST 插入和 BFS，作业把它们拼在一起：

- 先插入建 BST。
- 重复值忽略。
- 再层序输出。

你要注意 BST 的 BFS 不是按输入顺序输出，而是按建好的树结构层序输出。

### 26 实现堆结构

`tree.md` 既讲手写二叉堆，也讲 `heapq`。作业更适合直接用 `heapq`：

- `heapq` 默认小顶堆，正好用于“删除最小元素”。
- 多组数据，每组重新初始化堆。
- 操作 `type=1` 有参数，`type=2` 没参数。

这是从“理解堆原理”到“读操作流模拟”的拓展。

### 27 树的转换

`tree.md` 讲了左儿子右兄弟转换结构。作业不要求输出转换后的树，只要求高度。补充点：

- 原树高度只看向下孩子边。
- 转换后二叉树中，右兄弟边也算二叉树高度。
- 可以不建树，用 DFS 过程中的栈维护当前二叉深度。

这是典型的“题目只问指标，不必真的构造结构”。

### 28 Huffman 编码树

`tree.md` 对 Huffman 讲得很完整，包括建树和 WPL。作业只要最小 WPL：

- 每次取两个最小权值合并。
- 合并值加入答案。
- 合并值放回堆。

不需要生成编码，也不需要真的打印树。

### 49 二叉树的深度

md 里有遍历，作业补充输入形式：

- 第 i 行描述节点 i 的左右孩子。
- `-1` 表示空。
- 根固定是 1。

所以模板从 `depth(root)` 改成 `depth(index)`。

### 50 扩展二叉树

md 的遍历模板可以直接用，但输入是“带空标记的先序”。补充点：

- `.` 是空节点，不输出。
- 先序读入时每读一个字符，下标前进一次。
- 建树顺序必须是根、左、右。

### 53 根据二叉树中后序序列建树

和 22 对称。md 里重点是前中，作业补充中后：

- 后序最后一个是根。
- 中序负责分左右。
- 后序切分：左子树长度是多少，左后序就取多少。

### 54 验证二叉搜索树

`tree.md` 讲 BST 操作，作业问合法性。补充点：

- 不能只判断 `left < root < right`。
- 左子树所有节点都必须 `< root`，右子树所有节点都必须 `> root`。
- 用递归上下界：`valid(node, low, high)`。

### 1 单词序列

`graph.md` 的词梯问题就是基础。作业补充输入输出和距离口径：

- 单词是点，只差一个字母连边。
- BFS 找最短变换序列。
- 输出通常是序列长度，不是边数，所以起点距离常设为 1。

### 2 仙岛求药

来自迷宫 BFS。作业补充：

- 地图字符要找起点/终点。
- 输出可能是“经过格子数”而不是“移动步数”。
- 如果包括起点，起始距离设为 1；如果是时间，通常设为 0。

### 3 变换的迷宫

来自 `graph.md` 的迷宫变形。作业核心是时间周期：

- 墙/障碍会随时间变化。
- 同一个格子在不同 `t % K` 下不是同一个状态。
- `visited[x][y][t % K]` 是本题灵魂。

### 1 拓扑排序

`graph.md` 的拓扑排序用队列即可。作业常见补充是编号小优先：

- 若题目要求字典序/编号小优先，把队列换成最小堆。
- 每次弹出当前所有入度为 0 的最小编号点。
- 输出格式可能带 `v` 前缀，例如 `v1 v3`。

### 2 丛林中的路

来自 MST 的 Kruskal。作业补充：

- 输入是字母点名，先转编号。
- 每条边是无向边。
- 排序边后用并查集避免成环。

### 3 A Walk Through the Forest

这是作业里最值得重点复习的题，因为它不是单纯 Dijkstra。

对比 md：

- md 的 Dijkstra 是求最短距离。
- 作业先从家 2 跑 Dijkstra，得到每点到家的 `dist`。
- 然后 DFS 计数：只能从 `u` 走向 `dist[v] < dist[u]` 的邻居。

补充能力：最短路结果可以作为 DP 的“评价函数”，而不一定直接作为答案。

### 4 打怪救公主

来自 BFS 变形，但不是求最短步数，而是最大剩余血量。

需要改：

- `visited[x][y]` 不能是 True/False。
- 用 `best[x][y]` 记录到达该格子的最大剩余血量。
- 只有新血量更大，才继续扩展。

这是“同一位置可以被更优状态重访”的典型题。

### 5 兔子与樱花

来自 Floyd，但作业要求路径格式化输出：

- 地点是字符串，要映射成编号。
- Floyd 更新 `dist` 的同时更新 `nxt`。
- 输出路径时还要打印相邻点之间的边长。

### 56 拯救行动

来自 `graph.md` 的“进入守卫额外代价”例子。作业核心：

- 普通格代价 1，守卫格代价 2。
- 普通 BFS 不再适用。
- 用 Dijkstra，堆里放 `(time, x, y)`。
- 弹出终点时即可返回，因为 Dijkstra 保证此时最短。

### 57 连接所有点的最小费用

来自 MST。作业补充完全图与坐标边权：

- 任意两点都能连边。
- 边权是曼哈顿距离。
- 不需要真的生成 `O(n^2)` 边再排序；Prim 用 `minDist` 即可。

## 四、考试时从题面到代码的决策表

| 题面关键词 | 优先想到 | 代码骨架怎么选 |
|---|---|---|
| 最少步数、每步代价一样 | BFS | `deque` + `visited` |
| 迷宫会随时间变化 | 状态 BFS | `visited[x][y][t % K]` |
| 同一位置资源不同 | 最优值 BFS | `best[x][y]`，更优才入队 |
| 边权非负、代价不同 | Dijkstra | `heapq` + `dist` |
| 多个地点、多次查询最短路 | Floyd | `dist` + `nxt/prev` |
| 所有点连通，总费用最小 | MST | 显式边用 Kruskal，完全图用 Prim |
| 有向无环依赖顺序 | 拓扑排序 | 入度数组 + 队列/最小堆 |
| 路线数量，但要求越来越接近某点 | Dijkstra + DP | 先算 `dist`，再沿 `dist` 下降 DFS |
| 前序 + 中序 | 建树/直接递归 | 根 `pre[0]` |
| 中序 + 后序 | 建树/直接递归 | 根 `post[-1]` |
| 完全二叉树编号 | 区间扩张 | 每层 `[left,right]` |
| 每次取最小两个合并 | Huffman | 最小堆，答案累计合并值 |

## 五、代码迁移时的 7 个检查点

1. 输入结束条件是什么：EOF、`0`、`0 0`、还是先给 `T`。
2. 起点距离是 0 还是 1：问时间通常 0，问经过格子数可能 1。
3. `visited` 是布尔、三维状态，还是最优值数组。
4. 图是有向还是无向：无向边要两边都加。
5. 点编号从 0 还是 1 开始：题目 1..n 就开 `n+1`。
6. 是否要求路径：要求路径就必须保存 `parent/nxt/prev`。
7. 输出格式是否有额外符号：箭头、括号、`v` 前缀、末尾空格。

## 六、考前建议重点练的题型

优先级最高：

- 变换的迷宫：练状态 BFS，加深对 `visited[x][y][状态]` 的理解。
- 拯救行动：练“普通 BFS 何时升级 Dijkstra”。
- A Walk Through the Forest：练“最短路 + 记忆化 DFS 计数”的组合题。
- 兔子与樱花：练 Floyd 路径恢复和字符串点名映射。
- 连接所有点的最小费用 vs 丛林中的路：练 Prim/Kruskal 的选择。

树题重点：

- 22 和 53 放一起练：前中、后中切分不要混。
- 23 单独练：字符串解析时只切最外层逗号。
- 24 单独练：完全二叉树编号题别建树。
- 54 单独练：BST 验证用上下界，不是只看父子。

## 七、一句话复盘

这份作业真正考的是“模板变形能力”：你已经能看懂 md 里的标准代码，下一步要训练的是读完题后立刻判断：状态需不需要加维度、visited 需不需要改成最优值、BFS 需不需要升级 Dijkstra、树需不需要真的建出来、MST 应该用 Prim 还是 Kruskal。
